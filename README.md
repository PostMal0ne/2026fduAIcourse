### 一句话摘要

在本地两个模型（`qwen3:4b` 强 / `qwen3:0.6b` 弱，后者快 4–8 倍）之间做**按题型的路由**，
用「分桶 UCB1 + 收缩估计」在线学习，并在模型没见过的题上，用四类 baseline 与 95% 置信区间检验效果。

### 三条结论

1. **强模型在本题库上封顶**（5 个题型全部 100%），准确率没有提升空间 —— 任何路由都只会掉分。这是本次实验最重要的方法论发现。
2. **路由的价值在延迟约束下**：12 秒预算内路由可达 82.7%，而"只能用弱模型"只有 64.0%（+18.7 个百分点）；全用强模型需 19.0 秒，进不了预算。
3. **收缩估计是必需的**：不加收缩时小样本噪声会让系统把简单题错配给弱模型（75–85%，低于随机 82.0%）。

### 环境与复现

- Python 3.10+（仅标准库）、本地 Ollama；模型：`qwen3:4b`（约 2.5GB）、`qwen3:0.6b`（约 520MB）
- 全部实验：3 个 seed × 82 次模型调用，约 45 分钟，本机完成，无 API 费用
